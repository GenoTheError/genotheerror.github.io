🌊 Уровень 3

Уровень 3 — один из первых уровней, с которыми сталкиваются странники. Представляет собой серию длинных, тёмных, извилистых коридоров с бетонными полами, ревущими машинами и стенами из коричневого кирпича.

📊 Характеристики

Класс выживания Класс 3
Стабильность Нестабилен
Безопасность Опасен
Сущности Умеренное количество

📖 Описание

Уровень 3 — один из самых больших уровней Закулисья. Его площадь оценивается примерно в 350 миллионов квадратных миль. Коридоры очень узкие и замкнутые — для прохождения некоторых придётся нагибаться, горбиться, ползти или идти боком.

Стены сделаны из пыльного коричневого кирпича, покрытого сегментами медных труб и механических компонентов. Полы — из пыльного серого кафеля, потолки — полностью металлические.

По трубам течёт вязкий чёрный осадок — очень токсичный. Выделяет смертоносные пары, при вдыхании поражает нервную систему, при контакте с кожей — ожоги 2-й и 3-й степени.

👾 Сущности

  • Смертомоли — опасные насекомые
  • Гончие — агрессивные, быстрые
  • Скитальцы — выжившие, прячутся
  • Слухи о фигурах за решётками — не подтверждено

🚪 Входы

  • Через лифты на Уровне 2
  • Через noclip
  • Из некоторых других уровней

🏁 Выходы

  • На Уровень 4
  • Вернуться на Уровень 2
  • Редкие проходы на другие уровни
