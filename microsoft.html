🏢 Microsoft

Microsoft — американская корпорация, один из крупнейших производителей программного обеспечения в мире. Создатель Windows, Office, Azure и Xbox. В рейтинге Forbes Global 2000 за 2026 год Microsoft занял 7-е место (разделив с Bank of America). Капитализация — около $3,1–3,9 трлн.

🌍 Чем занимается

  • Windows — операционная система для ПК
  • Microsoft 365 (Office) — Word, Excel, PowerPoint
  • Azure — облачная платформа (конкурент AWS)
  • Xbox — игровое подразделение
  • Copilot — ИИ-ассистент на базе OpenAI
  • LinkedIn, GitHub — приобретённые сервисы

💡 Интересные факты

  • Microsoft — крупнейший инвестор OpenAI (ChatGPT), вложила в компанию более $13 млрд.
  • Azure — вторая по величине облачная платформа после AWS.
  • В 2026 году Microsoft сохранил место в топ-10 Forbes Global 2000, несмотря на рост конкурентов.
