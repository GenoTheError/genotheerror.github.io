🤖 DeepSeek

DeepSeek — китайский искусственный интеллект, разработанный компанией DeepSeek. Стал известен в 2025 году благодаря мощным моделям рассуждения, которые показывают результаты на уровне лучших мировых аналогов при значительно меньшей стоимости.

📖 Описание

DeepSeek была основана в Ханчжоу в 2023 году. Компания была создана при поддержке High-Flyer — китайского количественного хедж-фонда. Команда состоит из выпускников ведущих китайских университетов и технических специалистов из международных институтов.

Основная специализация — большие языковые модели. DeepSeek делает акцент на открытости (многие модели выкладываются в open-source) и низкой стоимости использования по сравнению с конкурентами.

✨ Возможности

  • Текст: понимание, генерация, анализ, перевод, решение задач
  • Контекстное окно: до 1 миллиона токенов (модель V4)
  • Загрузка файлов: TXT, PDF, PPT, Word, Excel, изображения
  • Поиск в интернете: доступен в ручном режиме
  • Рассуждения: модели V3.2 показывают результаты уровня золотых медалистов на IMO, CMO, ICPC, IOI

🕒 Версии

  • DeepSeek-R1 (январь 2025) — модель рассуждения, сопоставимая с OpenAI o1 при меньшей стоимости
  • DeepSeek-V3.1 (сентябрь 2025) — улучшения в Code Agent и Search Agent
  • DeepSeek-V3.2 (декабрь 2025) — сильные модели рассуждения, лидеры в open-source
  • DeepSeek V4 (апрель 2026) — миллион токенов контекста
  • DeepSeek V4.1 Flash (сентябрь 2026) — мультимодальное зрение
