🌊 The Hub

The Hub (Перекрёсток) — скрытый уровень Закулисья, служащий центральным узлом, соединяющим все остальные уровни. Представляет собой бесконечную сеть тускло освещённых туннелей с дорогой и дверями по бокам. Каждая дверь ведёт на определённый уровень. Считается одним из самых безопасных мест в Закулисье.

📊 Характеристики

Класс опасности 0 (безопасен)
Безопасность Стабилен
Размер Бесконечная сеть туннелей
Сущности Машины-Мимики (редко), Хранитель Ключей

📖 Описание

The Hub выглядит как огромный подземный комплекс с бесконечной сетью связанных между собой туннелей. Дорога вымощена гладким бетоном и имеет четыре полосы. Стены выложены бетонными плитами, а жёлтые промышленные лампы на потолке заливают всё тёплым оранжевым светом. В туннелях царит полная тишина.

По обе стороны дороги расположены большие бетонные двери, каждая с странным символом над ней. Символы не поддаются расшифровке, но их узоры напоминают круги на полях. Большинство дверей заперты — для открытия нужен соответствующий Ключ Уровня. Двери на Уровни 1, 11 и 178 всегда открыты.

⚠️ Опасности

  • Машины-Мимики — редкие транспортные средства, движущиеся на огромной скорости и сбивающие странников насмерть.
  • Невозможность покинуть The Hub через те же двери, через которые вошёл (двери исчезают).
  • Сложность найти нужную дверь без Ключа Уровня.
