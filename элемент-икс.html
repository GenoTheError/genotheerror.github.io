🎮 Element X

Element X — англоязычный ютубер, который делает видео по Minecraft с невероятными модификациями. Его фишка — использовать искусственный интеллект (ChatGPT, Claude) для написания кода, который меняет игру.

📖 Описание

Element X создаёт видео, которые выглядят как кликбейт, но на самом деле работают. Например, он кодил бесконечно распространяющуюся воду, взрывающихся кур и съедобные блоки. В работе использует Java и нейросети для модификации кода Minecraft.
